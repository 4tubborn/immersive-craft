# Immersive Craft

## Features

* Brew potions by right-clicking brewing stands while holding the required items.
* Display the available brewing times and current brewing progress.

## Usage

* Right-click the potion slots on a brewing stand to insert or remove potions.
* Right-click the center pillar to add or remove fuel.
* Hold a brewing ingredient and right-click the top of the brewing stand to add it.
